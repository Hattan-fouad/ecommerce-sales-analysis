# E-Commerce Sales Analysis

Simple data analysis project for e-commerce sales. Cleaned the data using Python and created an interactive dashboard on Tableau.

## What I Did:
- Cleaned missing values and prepared data using Python (Pandas).
- Calculated total sales and product quantities.
- Built a Tableau dashboard to visualize top selling products.

## Project Summary:
- **Total Revenue**: $710,240
- **Top Product**: Laptops
